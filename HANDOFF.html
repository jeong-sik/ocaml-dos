Gates

ZZT 런 관문 14 — 전부 실측으로 지정

  1. ROM INT 8 루틴 F000:0000 — 0x46C tick 범프 → INT 1Ch → EOI → IRET
  2. 전 IVT IRET 스텁 — TP의 옛 벡터 체인(AH=35h)이 0000:0000으로 추락 방지
  3. 호스트 서빙 벡터도 IVT 실주소 — TP Intr 썽크가 CD 없이 IVT 직독 retf
  4. BDA 초기화 0x40:0x463=0x3D4 — CRTC 상태포트 계산
  5. 포트 0x3DA 토글 — CRT 상승 에지 대기, 고정값이면 영구 갇힘
  6. IOCTL + 표준핸들 0-4 — 없으면 TP "Runtime error 006"
  7. BIOS 키 링 SSOT 0x40:0x1E — 포인터 클램프 [0x1E,0x3C]
  8. Cpu86.wake — HLT idle을 IRQ0로 해제
  9. string_op stride — lods=SI만, stos=DI만 (lodsb+stosw의 DI+3 화면 오염)
  10. load_com PSP 세그 0x1000 — 세그 0이면 PSP:0x80이 IVT[20h] 소거
  11. load_exe 0x9FF0 공식 — img_paras 헤더 제외, VRAM 미침범
  12. INT 10 비디오 배치 — 커서·스크롤·폰트 포인터 F000:FA6E
  13. INT 21 02/06/3C/40 — TP 에러메시지·LPT1 create·핸들 출력
  14. key@STEP 스케줄 — 사전 메뉴의 repeat-until-KeyPressed가 키를 먹음

게임 부트 관문은 전부 "실기 하드웨어 계약 부재"였다 — 게스트 코드는 옳고 호스트가 비어 있었다.
